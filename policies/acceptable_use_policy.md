# Acceptable Use & Data Handling Policy (Mock)

## 1. Purpose
This policy governs the acceptable use of company IT resources and the handling of sensitive data.

## 2. Data Classification
- **Confidential**: Customer PII, financial data, trade secrets, source code
- **Internal**: Internal communications, project documents, meeting notes
- **Public**: Marketing materials, published reports

## 3. Acceptable Use
- Company devices and networks are for business purposes
- Limited personal use is permitted during breaks
- All traffic on the company network may be monitored for security purposes

## 4. Data Transfer Rules
- Confidential data must NOT be transferred to personal cloud storage
- Approved transfer methods: Company-approved file sharing platforms only
- Large data transfers (>100MB) require manager approval
- Transfers to external parties require Data Protection review

## 5. Monitoring Notice
- Network metadata (not content) is analyzed for insider threat detection
- User identities are pseudonymized in the monitoring system
- De-anonymization requires evidence of risk AND management approval
- All monitoring activities are logged in an audit trail

## 6. Incident Response
1. **Detection**: Automated alert from monitoring system
2. **Triage**: Security analyst reviews alert (pseudonymized)
3. **Investigation**: If risk threshold met, request identity reveal with justification
4. **Escalation**: Notify CISO and HR if confirmed threat
5. **Response**: Containment, remediation, and documentation
6. **Review**: Post-incident review and policy update
